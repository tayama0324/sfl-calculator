# 厳密全探索の組合せ数・警告：追加仕様

## 目的と状態

厳密全探索を選んだとき、実行前に計算量の参考となる組合せ数を表示する。大きい場合は警告し、モンテカルロを選ぶ判断を助ける。v0.4.0で実装済み。条件探索では確定の近似計算には切り替えない。

シナリオ条件を考慮しない数を用いる。試合別の仮定固定も無視し、実結果の登録によって未消化日程から外れた試合だけを除外する。確定済み試合を未消化として数えない。

## 組合せ数の定義

現在のエンジンが扱う「集約後の試合状態」を対象とし、個々の勝敗順列そのものの数とは区別する。同じ集計状態に至る経路の確率は既存どおり厳密に合算される。

残り試合数をM、条件なしの1試合の集約状態数をSとすると、1ケースの条件未適用の組合せ数はS^M。

| 順位判定 | 現行モデルのS | 1ケースの組合せ数 |
| --- | ---: | --- |
| ポイントのみ | 6 | 6^M |
| バトルまで | 36 | 36^M |
| ラウンドまで | 426 | 426^M |

Sは確率モデルの状態分布から取得し、モデルが変更されても表示が追従するようにする。36・426を将来にわたる固定ルールとして扱わない。

基準を含む比較ケース数をKとし、全ケースの条件未適用の合計上限をK×S^Mと表示する。条件による絞り込み、同一ケースの再利用、順位が確定した部分木の一括集計は、この参考値に反映しない。

これは条件なしの結果の組合せ数であり、実際の探索ノード数・演算数・所要時間の厳密な上限ではない。内部ノードの処理も存在する一方、条件や集約で実際に処理する終状態数が大きく減る場合がある。

残り0試合はS^0=1とする。比較ケースを追加していなければK=1。各ディビジョンで独立に計算する。

## 表示

厳密全探索の設定領域に次を表示する。

- 未消化試合数Mと、1試合の集約状態数S。
- 1ケースの条件未適用の組合せ数S^M。
- 基準を含むケース数Kと、合計上限K×S^M。
- 「シナリオ条件・試合別固定・結果再利用・部分木集約を反映しない参考値」と明示。

値はBigInt等で正確に計算・保持する。大きい値は科学的記数法または桁数を使って読みやすくし、完全な整数も詳細表示またはコピーで確認できるようにする。所要時間への換算は初版の追加範囲に含めない。

順位判定、残り日程、実結果の登録・訂正・取消、比較ケース数が変わったら更新する。条件の内容や優先順位、固定スコアだけを変えても参考数は変わらない。

## 警告の初期基準

合計上限N=K×S^Mを用い、初期値として以下の段階を設定する。端末の性能や完了可否を保証する境界ではなく、保守的な注意表示の基準として扱う。しきい値はコード上の設定として調整できるようにする。

| 合計上限N | 表示 |
| --- | --- |
| N < 10^8 | 組合せ数を通常表示 |
| 10^8 ≤ N < 10^12 | 注意：計算に時間がかかる可能性があります |
| N ≥ 10^12 | 強い警告：条件未適用では非常に大規模です。現実的な時間で終わらない可能性があります |

警告には「条件や集約によって実際の処理量は減る場合があります」と添える。特定の時間内の完了や、必ず完了しないことを断言しない。しきい値未満でも高速な完了は保証しない。

警告は実行前から画面内に表示する。厳密計算を禁止せず、追加の確認ダイアログも設けない。ユーザーはそのまま計算できる。「モンテカルロに切り替える」操作を用意しても、自動切替・自動実行はしない。

## 検証

条件探索への適用は[条件探索仕様](condition-search.md)を参照。選択した1チーム・1目標・1前提での実行ではK=1として参考数を表示する。複数の成績指標を同時集計することを、独立したケースの再探索と混同してKへ重複加算しない。必要な集計や高速化条件が異なるため、確率計算と同じ所要時間とは保証しない。条件探索ではモンテカルロへ切り替えて確定条件を得る操作は設けず、近似値を見たい場合は別機能の「順位確率」へ移動する。

- S=6・36・426と各モデルの集約状態数が一致する。
- M=0、9、12、および大きい整数のべき乗を確認する。
- 全勝等や全スコア固定を指定しても参考数が変わらない。
- 実結果登録でMが減り、取消で戻る。
- ケース数の変更で合計上限が変わる。
- 10^8・10^12の境界で警告段階が正しく変わる。
- モンテカルロの試行数と、この厳密計算の参考組合せ数を混同しない。
- 警告によって計算が禁止されたり、自動で方式が変更されたりしない。
