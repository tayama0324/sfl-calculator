# 完全一致時の追加タイブレーク戦：出典記録

ユーザーが公式の競技細則を確認し、同成績のチームは追加タイブレーク戦を行うことの裏付けが取れたと、本チャットで報告した。これに基づき、従来の作業上の仮定を確定ルールへ更新する。

対象はポイント・バトル得失点差・ラウンド得失点差の3項目完全一致。追加戦の実施が確認されたことと、その勝敗が未計算であることを区別する。

- 目標の境界で完全一致：達成の可能性は残るが、追加戦の勝利を保証しない。
- 同点グループ全体が目標順位以内：追加戦の勝敗にかかわらず、その目標は達成確定。
- 追加戦の方式・勝率・勝敗を新たにモデル化しない。既存の上下限と条件探索の判定式は維持する。

確認の主体はユーザー。この更新時点で、アシスタントによる細則本文の直接閲覧は行っていない。文書URL、版、条番号および本文の引用は本チャットでは提供されていないため、独立に閲覧・照合済みとは記載しない。公式日程の直接照合が未完了という既存の記録は、この確認によって変更しない。
